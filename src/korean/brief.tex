\end{itemize}
\section{주요 구축 경험}
\begin{itemize}[leftmargin=0.15in, label={}]
\small{
\item{\textbf{요구사항 발굴부터 MLOps 신규 구축까지 주도:} 연구자 인터뷰와 데이터·코드·실행 방식 분석으로 담당자 의존, 분산된 데이터, 버전·계보 부재를 요구사항으로 구체화했습니다. Airflow의 실행·재시도, dbt의 SQL 변환, Iceberg의 테이블 버전, DataHub의 계보 관리 역할을 정의하고 공통 플랫폼을 설계·구현했습니다.}
\item{\textbf{온프레미스 베어메탈 Kubernetes 구축·운영:} 플랫폼 2인 팀에서 클러스터 구성을 단독 담당했습니다. 사내 장비로 10노드 클러스터를 구축하고 네트워크·스토리지·인증·실행 환경을 12개 Pulumi 스택으로 코드화했습니다(2026.09 기준). 변경 이력과 스택 간 의존성을 관리해 인프라를 재구성할 수 있는 기반을 마련했습니다.}
\item{\textbf{하드웨어 전반의 구성과 운용 주도:} 유휴 PC·워크스테이션을 분해해 RAM·NVMe를 회수·재장착하고, 네트워크 장비 선정·교체까지 직접 수행했습니다. NUMA·듀얼채널 구성과 메모리 압박·swap을 점검하고 PostgreSQL 데이터 디스크를 분리하는 등 실제 워크로드에 맞춰 장비와 시스템을 함께 조정했습니다.}
\item{\textbf{Iceberg 카탈로그와 DuckDB 조회 계층 설계:} SeaweedFS의 S3 호환 저장소와 Iceberg REST Catalog로 Silver/Gold 데이터·메타데이터를 관리하고 NVMe/HDD 티어를 구성했습니다. PostgreSQL + pg\_duckdb 조회 환경을 마련하고, 차원 테이블 생성 시 카탈로그에서 최신 메타데이터 경로를 조회해 DuckDB에 전달하도록 구현했습니다. 파일명으로 버전을 추정하지 않고 카탈로그를 기준으로 데이터를 읽도록 했습니다.}
\item{이전 경력: AWS EMR/PySpark 미술 시장 ETL 파이프라인 총괄(Eazel, 팀 리드).}
}
\end{itemize}
