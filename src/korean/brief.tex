\section{요약}
\begin{itemize}[leftmargin=0.15in, label={}]
    \small{\item{
    온프레미스 Kubernetes 위에 MLOps 플랫폼을 혼자 설계·구축·운영하는 엔지니어입니다. HUINNO 에서 6개월간 수집 → 레이크하우스 → 변환 → 계보 → 분산 학습 → 실험·모델 레지스트리까지 전 구간을 \textbf{Pulumi(Python IaC)}로 코드화했고, 플랫폼 2인 팀에서 \textbf{클러스터 구성은 단독}으로 맡았습니다. 도구를 늘리기보다 사람이 병목인 자리를 찾아 없애는 쪽을 택하고, 결정은 실측으로 내립니다. 그 전에는 iOS 개발자로 시작해 백엔드·프론트·클라우드 데이터 파이프라인을 거쳐 데이터 엔지니어링 팀을 리드했습니다.
    }}
\end{itemize}

\section{핵심 성과 (2026-09 실측)}
\begin{itemize}[leftmargin=0.15in, label={}]
    \small{
    \item{\textbf{인프라 12개 Pulumi 스택 전부 과반 작성} — 스택 코드 변경의 93\%(6개는 96\% 이상). 저장소 커밋 1,204건 중 92\% 직접 작성, 머지 PR 678건.}
    \item{\textbf{10노드 · 상시 pod 235개 · 사내 서비스 23종}을 프로덕션 운영. 23종 전부에 Dex(GitHub OIDC) + oauth2-proxy SSO 를 적용하고 같은 신원을 Kubernetes RBAC 까지 연결.}
    \item{\textbf{ETL 저장소 커밋 1,599건 중 83\% 작성} — 공용 프레임워크 93\%, CAST · MIMIC-IV · 운영 파이프라인 각 100\%. Airflow 3.x + dbt + Apache Iceberg 로 데이터셋 준비의 1인 의존을 제거하고 DataHub 에 계보를 자동 기록.}
    \item{\textbf{학습 데이터 전달 25배 단축} — 네트워크·스토리지 재설계로 iperf3 실측 \mbox{93.7\,Mbps} → \mbox{2.5\,Gbps}, \mbox{8\,TB 기준 8.4일 → 7.8시간}.}
    \item{\textbf{GPU 증설 결정을 실측으로 전환} — 10일 측정 결과 가동률 \mbox{5.3\%} · 대기 \mbox{0건}, 병목은 유휴 세션이 점유한 \mbox{1,112 GPU-시간}(점유의 91\%). 구매 대신 할당 회수로 방향을 바꿈.}
    \item{\textbf{AI 에이전트를 상시 투입해 1인 처리량을 팀 규모로} — 그 속도를 SDK 단위 테스트 719건 · CI 게이트 · 실패 기록 23건 · \mbox{PRD 30건}으로 받침.}
    \item{\textbf{이전 경력:} StarRocks \textbf{PoC}로 분석 쿼리 \mbox{7초} → \mbox{1.4초}(80\% 단축) 검증(Cellkey). \mbox{AWS EMR/PySpark} 미술 시장 \mbox{ETL 파이프라인} 총괄(Eazel, 팀 리드).}
    }
