# 플랫폼별 텍스트

LaTeX 이력서(`src/`)를 기준으로 구직사이트 입력란에 붙여 넣을 문구를 관리합니다.
2026-10-02 기준 한글·영문 이력서와 내용을 맞췄습니다. 실제 사이트 프로필 수정은 별도입니다.

| 파일 | 플랫폼 | 언어 | 구성 |
|---|---|---|---|
| `wanted.md` | 원티드 | 한국어 | 소개·상세 경력기술서·기술 스택·자격증 |
| `remember.md` | 리멤버 | 한국어 | 짧은 소개·경력 요약·핵심 역량·이전 경력 |
| `linkedin.md` | LinkedIn | 영어 | Headline·About·Experience·자격증 |

## 공통 작성 기준

- 코드 블록 내부는 그대로 복사할 평문입니다. 파일의 제목과 작성 안내는 입력하지 않습니다.
- 연구자 인터뷰를 통한 문제 정의, 기술 선정, 신규 설계·구축을 먼저 설명합니다.
- 기존 문제는 분산 저장, 생산자에게 집중된 암묵지, 생성 코드의 버전 관리 부재, SSH 전달, Notion 기반 모델·성능 공유입니다.
- 플랫폼 2인 팀에서 클러스터 구성은 단독 담당했으며, 하드웨어 구성·운용은 직접 주도했습니다.
- 10노드·12개 Pulumi 스택은 2026.09 기준입니다. 커밋 수를 성과로 내세우거나 신규 구축을 속도 개선으로 표현하지 않습니다.
- SeaweedFS의 S3 호환 저장소와 Iceberg REST Catalog, 카탈로그 메타데이터를 이용한 DuckDB 조회 설계를 구분해 설명합니다.
- manifest 동결·복원, MLflow 트래킹·모델 레지스트리는 구축했습니다. 연구 코드 연동과 전체 재현 검증은 진행 중입니다.
- 제품명은 제외하고 기술명은 유지합니다. 정보처리기사와 OPIc AL을 포함합니다.
- 입력란 제한은 실제 사이트에서 확인합니다. 길이가 부족하면 각 파일의 축약 안내를 따르되 본인 역할과 진행 상태는 유지합니다.
