# 플랫폼별 텍스트

LaTeX 이력서(`src/`)가 정본이고, 여기는 **플랫폼 입력란에 그대로 붙여 넣는 평문**이다.
잘라 쓴 게 아니라 각각 다시 썼다 — 제약과 읽는 사람이 다르기 때문이다.

| 파일 | 플랫폼 | 언어 | 특징 |
|---|---|---|---|
| `linkedin.md` | LinkedIn | 영어 | 리크루터 검색이 키워드로 걸린다. 헤드라인·About 이 따로 있다 |
| `wanted.md` | 원티드 | 한국어 | 경력기술서가 길게 들어간다. 기술 태그가 검색 축 |
| `remember.md` | 리멤버 | 한국어 | 명함 기반이라 짧다. 한 줄 소개가 사실상 전부 |

## 공통 규칙

- **마크다운이 안 먹는다.** 셋 다 평문 입력란이라 `**굵게**` 가 그대로 별표로 보인다.
  강조는 문장 구조와 숫자로 한다.
- 글머리는 `·` 또는 `-` 를 직접 넣는다.
- 숫자는 정본(`src/`)과 일치시킨다. 한쪽만 고치면 어긋난다.
