```
· Airflow·dbt 변환과 DataHub 계보를 구현하고, SeaweedFS Iceberg REST Catalog·S3 저장소 및 PostgreSQL + pg_duckdb 조회 계층 구축
· manifest 동결·복원 도구, MLflow 트래킹·모델 레지스트리 구축. 연구 코드 연동과 전체 재현 검증은 진행 중
```

## 핵심 역량

```
■ 요구사항 발굴과 신규 플랫폼 설계
연구자 인터뷰와 기존 데이터·코드·실행 방식 분석으로 문제를 정의했습니다.
Airflow의 실행·재시도, dbt의 SQL 변환, Iceberg의 버전 관리,
DataHub의 계보 관리 역할을 나누고 공통 플랫폼을 구현했습니다.

■ 온프레미스 인프라와 하드웨어 운용
사내 베어메탈 Kubernetes 클러스터 구성을 단독 담당했습니다.
유휴 PC·워크스테이션 부품을 재활용하고 네트워크 장비를 선정·교체했습니다.
NUMA·듀얼채널, 메모리 압박·swap, 데이터 디스크 분리까지 조정했습니다.

■ Iceberg 카탈로그와 SQL 조회 설계
SeaweedFS REST Catalog와 S3 호환 저장소로 데이터·메타데이터를 관리합니다.
카탈로그에서 최신 메타데이터 경로를 조회해 DuckDB에 전달하고,
PostgreSQL + pg_duckdb로 공통 SQL 조회 환경을 구축했습니다.

■ 데이터 버전과 재현 기반
Notion에 공유되던 모델·성능과 데이터·코드·환경을 연결할 기반을 마련했습니다.
manifest 동결·복원 도구와 MLflow 트래킹·모델 레지스트리를 구축했습니다.
연구 코드 연동과 데이터부터 모델까지의 전체 재현 검증은 진행 중입니다.

■ 데이터 엔지니어링과 협업
AWS EMR/PySpark 파이프라인을 구축하고 데이터 엔지니어링 팀을 리드했습니다.
연구자는 도메인 ETL을, 플랫폼은 실행·계보·검증·재시도를 맡도록 역할을 정의합니다.
```
